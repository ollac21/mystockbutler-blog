# Fiscal.ai : avis, prix et alternatives (2026)

Une « beautiful all-in-one research platform », une API de flux de données et des connecteurs pour vos outils d’IA. Il vous donne les données et vous laisse l’analyse.

La page des prix de Fiscal.ai, le 4 novembre 2026, n’affiche aucun prix. Elle propose trois produits : le Terminal, une « beautiful all-in-one research platform » ; MCP, « accurate financial data connected into your AI tools » ; et l’API, « the data feed API that powers the data behind institutions and investing platforms ». Le Terminal et MCP comprennent chacun un essai gratuit de 7 jours à l’inscription.

Si vous construisez vos propres modèles ou alimentez un outil d’IA en données, sa documentation API liste ce que vous obtenez : les États-Unis, le Canada, les ADR américains, le Royaume-Uni et l’UE, avec 20+ périodes annuelles et 40+ périodes trimestrielles de données financières et 30+ ans de cours. Si vous voulez que l’entreprise soit lue pour vous, un rapport complet fait ce travail.

Il propose un essai gratuit de 7 jours du Terminal et de MCP à l’inscription ; sa documentation API dit qu’obtenir une clé « starts a free trial (no credit card) ».
